# テスト記録

## 実機で確認した動作

2026年11月11日にSteam Frame上で手動対応を行い、Resonite `2026.11.11.21`、Steam build `26579448` のVR起動、内蔵スピーカーの音声出力、FBXモデルの表示を確認しました。マイクの音声入力も、その後ユーザーが動作を確認しています。

mikktspaceの追加前には、ARM64 .NETの分離プロセスからゲーム同梱の.NETラッパーを呼び出しました。既知の三角形と、失敗していた2つのFBXで接線の計算が通りました。その後、実ゲームの再インポートでもモデルが表示されました。

## インストーラーの検証

18件の単体テストで、起動スクリプトの既知形式と未知形式の扱い、VDFの読み書き、取得アーカイブのパス検査、バックアップからの復元、導入後の変更を上書きしないこと、ほかのアプリの設定保持、起動中ガード、同時実行の拒否、x64環境での適用拒否、更新後も最初のバックアップへ戻せること、更新途中で止まった場合の復元、動画ランチャーの引数の保持などを確認しました。

`install.sh` を変更する場合は `src/resonite_frame.py` を編集し、次のコマンドで生成・検証します。

```bash
python3 tools/build_installer.py
python3 -m unittest discover -s tests -v
python3 tools/build_installer.py --check
bash -n install.sh
```

Frameでは、自己完結した `install.sh --check` を動いている実ゲームに対して実行しました。ARM64 runtimeと必要なライブラリを確認でき、ゲームの終了や設定変更は行っていません。

自動導入のテストには、Frame上の一時ディレクトリに作ったSteam環境を使います。実ゲームから.NET runtimeを読み取り専用の参照元として複製し、それ以外はテスト用の設定と起動スクリプトを作ります。ライブラリの収集、mikktspaceのビルドと計算テスト、導入、2回目の実行、チェック、復元を通し、ほかのアプリの設定や導入後の無関係な設定変更が保持されることも確認します。パスには空白を含めています。

2026年11月12日には、`v0.1.0` で導入済み.NETを使う場合と、Microsoftから.NETを新規取得する場合の両方で、この一連のテストが通りました。新規取得ではARM64 runtimeアーカイブのSHA512検証と展開も確認しています。

Frame上で再現する場合は、取得したリポジトリのルートから実行します。

```bash
python3 tools/test_on_frame.py \
  --installer ./install.sh \
  --game "$HOME/.local/share/Steam/steamapps/common/Resonite"
```

このテストはゲームやSteamを起動・終了・再起動しません。実ゲームの `LinuxBootstrap.sh` と既存の起動ヘルパーについて、テスト前後のハッシュが同じであることも確認します。

Microsoftからの新規runtime取得も試す場合は、同じコマンドに `--fresh-runtime` を付けます。

## 動画・画像対応の検証

動画はARM64版yt-dlpとDenoの実行、既知のMP4 URLと以前失敗したYouTube URLの情報取得を確認しました。ゲーム同梱の `NYoutubeDL.dll` からも情報を取得できています。YouTube URLでは20種類の形式が返りました。

画像は、ゲーム同梱の.NETラッパーと、インストーラーのネイティブテストの両方でBC1・BC3・BC7の圧縮・展開を確認しました。16×16のテスト画像に対して、元の画素との最大差はそれぞれ1・1・0です。さらに、ゲームと同じ依存ファイルを読み込む分離プロセスで、100×82のPNGをゲームの `Texture2DVariantGenerator.GenerateVariants` に渡し、BC1_LZMAの変換結果を生成できました。

`v0.2.0` では、Frame上の隔離環境で `v0.1.0` からの更新と、.NETを新規取得する導入の両方を検証し、再実行、チェック、復元まで通りました。動画ランチャーは、Resoniteと同じ更新・バックアップ復元の処理を経てもARM64版を呼び出せます。ゲーム同梱のラッパーからnightly更新の呼び出しを行った後も、YouTube URLの情報を取得できました。復元後には、元の動画ツールとバックアップ、2つの画像変換ライブラリが戻ることも確認しています。

2026年11月12日には、実際のResoniteへ `v0.2.0` を適用しました。起動中Steamの設定APIで書き込み・読み戻しが通り、その後のVR起動と内蔵スピーカー・マイクの認識もログで確認しています。
